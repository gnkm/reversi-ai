# 強化学習 (対称な読み)

自己対局で学んだ **対称な線形の評価** を葉にして、**数手先を読んで** 合法手を選ぶ。WTHOR は使わない。対局時にニューラルネットワークの推論も OpenRouter も使わない。終盤の完全読みはしない。

## 学習

算法は線形の TD(0) のままである。変えるのは学習の進め方だけである。

- 学習率 \(\alpha\) と探索率 \(\varepsilon\) は、最初の局の値から線形に下がる。最後の局の \(\alpha\) は初期値の 0.1 倍、\(\varepsilon\) は 0 である。
- \(\varepsilon\) で選んだ手の直後の局面は、貪欲方針の価値の目標に使わない。その手の直前も、その局面自体も更新しない。
- 盤を回転・反転して一致するマスは、黒平面どうし・白平面どうしで同じ重みを共有する。
- 特徴は黒と白だけである。空平面は黒＋白＋空＝1 から切片と線形従属なので、重みは 0 のままである。

報酬は勝敗（黒勝ち \(+1\)、白勝ち \(-1\)、引き分け \(0\)）のままである。パターン特徴、TD(λ)、石差の報酬、終盤完全読みは入れない。

成果物は `models/rl-tied.json` である。既存の `models/rl.json` は置き換えない。

## 着手

着手は深さ 4 のアルファベータ（Negamax）である。探索の並べ方と置換表はルールベース (αβ) と同じ関数を使い、葉だけをこのファイルの線形 \(v\) にする。白番は符号を反転する。葉の外に閾値や定数ボーナスは足さない。同点は a1…h8。

既存の「強化学習 (自己対局)」は 1 手読みのまま残す。「強化学習 (自己対局＋読み)」は `models/rl.json` の葉のまま残す。
