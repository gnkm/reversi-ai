# RL 改善 段階 4（終盤完全読み）

数値の正本は [`rl-stage4.json`](rl-stage4.json) である。開始局面は段階 0 の [`rl-openings.json`](rl-openings.json) をそのまま使う。本ファイルはそれを要約する。表の小数は閲覧用に丸めた写しであり、再計算して正本にしない。対局の再実行は CI に載せない。

提案書は作業稿であり、本ファイルは [`docs/source-of-truth/`](../source-of-truth/) には置かない。勝率の数値目標は **shall にはしない**。思考時間や空きマス数の数値を要求にはしない。

## 測ったもの

比較は同じ評価関数同士である。葉は段階 3 のパターン特徴（`models/rl-pattern.json`）。一方だけ、空きマスが閾値以下ならヒューリスティックを使わず終局まで読み、葉を最終石数差（自分 − 相手）にする。評価関数の差し替えと効果を混同しない。WTHOR も対局時の NN も OpenRouter も使わない。

| 項目 | 内容 |
| --- | --- |
| 候補 | 同じパターン評価＋終盤完全読み（`rl_pattern`。閾値は空きマス 10） |
| 相手 | 同じパターン評価。終盤でも深さを延長しない |
| 開始局面 | 段階 0 と同じ 200 局面。乱数種 `20260922` |
| 深さ | カタログと同じ 4。各局面で先後入れ替え。400 局 |
| 勝敗 | 公式スコア。勝率は完全読みあり側の（勝 + 0.5×分）/ 局数 |
| 石数差 | 盤上の石数（完全読みあり − なし） |
| 判定 | 勝率の 95% 区間が 0.5 を上回れば改善。またぐときは「この局数では区別できない」 |

既存の「強化学習 (自己対局)」「強化学習 (自己対局＋読み)」「強化学習 (対称な読み)」は終盤完全読みを持たないまま残す。ルールベース (αβ) の終盤読みは別個体であり、本段階の完了条件にしない。

## 閾値

1 手の思考時間の上限（この記録では 2 秒）から決めた。shall ではない。目安は 10〜14。開始局面から深さ 4・完全読みなしで進め、空きマス 10・12・14 の局面を各 8 個測った。

| 空きマス | 平均秒 | 最大秒 | 2 秒以内 |
| ---: | ---: | ---: | --- |
| 10 | 0.44 | 0.91 | はい |
| 12 | 2.53 | 4.24 | いいえ |
| 14 | 17.08 | 26.92 | いいえ |

採った値は **10** である。コードの `EXACT_EMPTY` と同じ。Python の 8×8 配列のままなので、12 以上は家庭用 PC の 1 手として長い。

## 結果

記録: [`rl-stage4.json`](rl-stage4.json)（`recorded_at` 2026-09-22 13:29）。深さ 4。

| 局 | 勝 | 分 | 負 | 勝率 | 95% 区間 | 平均石差 | 判定 |
| ---: | ---: | ---: | ---: | ---: | --- | ---: | --- |
| 400 | 233 | 6 | 161 | 0.590 | 0.542–0.638 | +6.58 | 完全読みあり |

完全読みあり側の勝率の 95% 区間は 0.5 を上回る。同じ評価関数でも、終盤を読み切ると強さが上がる。見出しの勝率・平均石差・95% 区間はこの表である。正本の `wins` / `draws` / `losses` を見る。

カタログ全体の順位は参考値である。改善の判定には上の表を使う。正本は [`round-robin.json`](round-robin.json)、推移は [`history.md`](history.md) である。対局 API は使わず、ホストの着手関数を直接呼ぶ。ランダム (一様) と生成 AI (Jev) は非決定的なので、再実行で勝敗は変わりうる。
