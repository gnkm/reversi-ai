# RL 改善 段階 3（パターン特徴と TD(λ)）

数値の正本は [`rl-stage3.json`](rl-stage3.json) である。開始局面は段階 0 の [`rl-openings.json`](rl-openings.json) をそのまま使う。本ファイルはそれを要約する。表の小数は閲覧用に丸めた写しであり、再計算して正本にしない。学習と対局の再実行は CI に載せない。

提案書は作業稿であり、本ファイルは [`docs/source-of-truth/`](../source-of-truth/) には置かない。勝率の数値目標は **shall にはしない**。

## 測ったもの

比較は同じ深さの αβ 同士である。候補の葉はパターン特徴（`models/rl-pattern.json`）、相手は段階 2 の線形 \(v\)（`models/rl-tied.json`）と、位置評価（`POSITION_SCORES` / `minimax.leaf_score`）である。白番の価値は符号を反転する。葉の外に閾値や定数ボーナスは足していない。終盤完全読みはしない。WTHOR も対局時の NN も OpenRouter も使わない。

| 項目 | 内容 |
| --- | --- |
| 候補 | αβ＋パターン評価（`rl_pattern`）。既定の深さは 4 |
| 相手 | 同じ深さの αβ＋段階 2 の線形 \(v\)、および αβ＋位置評価 |
| 開始局面 | 段階 0 と同じ 200 局面。乱数種 `20260922` |
| 深さ | 1、2、4。各局面で先後入れ替え。深さごとに 400 局 |
| 勝敗 | 公式スコア。勝率は段階 3 側の（勝 + 0.5×分）/ 局数 |
| 石数差 | 盤上の石数（段階 3 − 相手） |
| 判定 | 勝率の 95% 区間が 0.5 を上回れば改善。またぐときは「この局数では区別できない」 |

学習は自己対局の TD(λ) である。活性な項目数で α を割る。隣の段階へ更新の半分を足す。短い比較で報酬と λ を選び、本番は乱数種 0 で 24000 局まで回した。カタログの重みは学習曲線の頂点である **16000 局** である。

## 報酬と λ の短い比較

各案を 2000 局学習し、開始局面 40（深さ 2）で測った。正本の `reward_trials` を見る。

| 案 | 段階 2 への勝率 | 位置評価への勝率 |
| --- | ---: | ---: |
| 勝敗・λ=0.5 | 0.412 | 0.425 |
| 勝敗・λ=0.7 | 0.425 | 0.344 |
| 勝敗・λ=0.9 | 0.450 | 0.463 |
| 石差・λ=0.7 | 0.400 | 0.219 |

勝敗の三案の区間は重なる。石差は位置評価に対して勝率の 95% 区間が 0.5 を下回る。採った定義は **勝敗（+1/0/−1）と λ=0.9** である。

## X / C の重み

辺＋2X の表で、X を黒にした並びに対し、角 a1 が空のときと黒のときを比べる。他のマスは空である。16000 局の重みでは、**すべての段階で符号が変わる**（空の角では負、自角では正）。角 3×3 の C だけの並びに対する重みは、この学習では 0 のままである。正本の `xc` を見る。

## 総当たり

カタログ全体の順位は参考値である。改善の判定には上の表を使う。正本は [`round-robin.json`](round-robin.json)（`recorded_at` 2026-09-22 21:19）、推移は [`history.md`](history.md) である。14 個体、各対で先後を入れ替えた 2 局。対局 API は使わず、ホストの着手関数を直接呼んだ。ランダム (一様) と生成 AI (Jev) は非決定的なので、再実行で勝敗は変わりうる。

| 順 | 個体 | 勝-分-負 | 点 |
| ---: | --- | --- | ---: |
| 1 | 強化学習 (パターンの読み) | 24-0-2 | 24 |
| 2 | ルールベース (αβ) | 22-0-4 | 22 |
| 3 | 強化学習 (対称な読み) | 21-1-4 | 21.5 |

| 9 | 強化学習 (自己対局) | 9-2-15 | 10 |

初形から 2 局だけの総当たりでは、パターンの読みが 1 位である。開始局面集合での深さ 4 の比較でも段階 2 と位置評価の両方に勝っているが、総当たりの順位は改善の判定に使わない。既存の 1 手読みは 9 位のまま残っている。
