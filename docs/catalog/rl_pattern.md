# 強化学習 (パターンの読み)

自己対局で学んだ **パターン特徴** を葉にして、**数手先を読んで** 合法手を選ぶ。WTHOR は使わない。対局時にニューラルネットワークの推論も OpenRouter も使わない。終盤の完全読みはしない。

## 評価

盤の決まったマスの組を一つの単位にし、その組の黒・白・空の並びごとに重みを持つ。評価は、今の局面に現れた並びの重みを足したものである。マスごとの 192 次元の配置特徴ではない。

共有する組は次のとおりである。並びの代表は a1 側で、回転と反転で重なる組は同じ表を使う。

- 辺＋2X。a1 から h1 と、X の b2・g2。
- 角の 3×3。
- 角の 2×5。
- 長さ 4 から 8 の斜め。
- 辺から 2・3・4 列目の直線。

石数で 10 段階に分け、段階ごとに別の表を持つ。4 個から 6 個ずつで、最後の段階は 58〜64 である。更新するとき、隣の段階にも半分の大きさで同じ更新を足す。

スカラーは着手可能数の差（mobility）、空きマスに接する石の数の差（フロンティア）、残り空きマスの偶奇（パリティ）である。mobility とフロンティアは 8 で割ってから重みを掛ける。パリティは、パスが無いとしたときに黒が最後の石を打つなら +1、そうでなければ −1 である。

## 学習

算法は自己対局の TD(λ) である。短い自己対局（各 2000 局、開始局面 40）で λ を 0.5・0.7・0.9、報酬を勝敗と石差で比べ、**報酬は勝敗（黒勝ち +1、白勝ち −1、引き分け 0）、λ は 0.9** を採った。石差報酬は位置評価付き αβ に対して勝率の 95% 区間が 0.5 を下回った。活性な項目の数で学習率を割る。α は最初 0.05 で、全対局を通してその 20% まで線形に下げる。ε は最初 0.1 で、対局数の 70% で 0 まで下げる。ε で選んだ手の直後は、貪欲方針の価値の目標に使わない。

本番の学習は乱数種 0 で 24000 局まで回し、4000 局ごとの重みを深さ 2 で段階 2 と比べた。勝率は 16000 局で最も高く、それ以降は下がる。カタログに載せる重みは **16000 局** のものである。数値と区間は [段階 3](../benchmarks/rl-stage3.md) を見る。

辺＋2X の表では、同じ X 黒の並びに対して角 a1 が空のときと黒のときで、重みの符号が段階ごとに変わる。角 3×3 の C だけの並びに対する重みは、この学習では 0 のままである。

成果物は `models/rl-pattern.json` である。既存の `models/rl.json` と `models/rl-tied.json` は置き換えない。

## 着手

着手は深さ 4 のアルファベータ（Negamax）である。探索の並べ方と置換表はルールベース (αβ) と同じ関数を使い、葉だけをこのパターン評価にする。白番は符号を反転する。葉の外に閾値や定数ボーナスは足さない。同点は a1…h8。

既存の「強化学習 (自己対局)」は 1 手読みのまま残す。「強化学習 (自己対局＋読み)」と「強化学習 (対称な読み)」も、それぞれの線形の重みのまま残す。
