# ルールベース (定石)

短い定石列に乗っているあいだはそれに従い、外れたら位置評価と同じ規則に切り替える。対局中に定石列は増やさない。WTHOR から定石を読み込まない。同点は a1 から h8 の座標順。

## 3 列

座標は a1 が黒から見て左下。石を置くマスだけを並べ、パスは含めない。

| 名 | 着手列 |
| --- | --- |
| 縦取り・虎 | f5, d6, c3, d3, c4 |
| 斜め取り・牛 | f5, f6, e6, d6, c5 |
| 並び取り・鼠 | f5, f4, e3, f6, d3 |

盤は 90 度回転 0〜3 回と、各々に左右反転の有無で 8 通りに重なる（正方形の対称、位数 8 の二面体）。初手が c4、d3、e6 の対局も、回転や反転で f5 始まりと同じなら定石に乗る。

現在までに置いたマスの列を \(M\) とする。パスが 1 回でも含まれていれば定石から外れたとみなす。8 対称のそれぞれについて、上表のいずれかの列 \(L\) が変換後の \(M\) の接頭辞になっており、\(L\) の次のマスを逆変換したマスがいまの合法手なら、そのマスを候補にする。候補が 1 つ以上あればその中から選び、無ければ位置評価に任せる。候補が複数あるときは a1、b1、…、h1、a2、…、h8 の順である。例えば黒が f5 のあと白番なら、候補は f4・d6・f6 であり、f4 を選ぶ。

```python
candidates = _book_candidates(position)
for square in legal_places(position):
    if square in candidates:
        return Place(square)
return choose_positional(position, rng)
```

対局中に学習済みモデルも OpenRouter も呼ばない。
