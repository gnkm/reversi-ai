# ルールベース (αβ)

深さ 4 の **Negamax** 形式のアルファベータ探索で合法手を選ぶ。Negamax は、相手番の評価を符号反転して常に最大化する書き方である。ミニマックス個体と同じ深さであり、空きマスが少なくても終局まで延長しない。深さを対局中に変えない。

葉の点数は位置評価の点数表ではない。探索の速さのための並べ替えと、同じ局面の再探索を省く表を使う。選ぶ手のタイブレークは根で a1…h8 であり、探索順では決めない。

## アルファベータ法

ある手が既に十分悪いと分かれば、残りの枝を見なくても最善は変わらない。その切り捨てを **アルファベータ法** という。α はこれまで確保した下限、β は相手が許す上限である。\(\alpha \ge \beta\) ならその節点は捨ててよい。

Negamax では子の値を \(-v\) として受け取る。

```python
child_value = -_negamax(
    child, ply + 1, -beta, -alpha, limit, order, nodes, table
)
value = max(value, child_value)
alpha = max(alpha, value)
if alpha >= beta:
    break
```

## Move Ordering

枝刈りは、よい手を先に読むほど効く。探索の直前に合法手を並べ替えることを **Move Ordering** という。優先は次の順である（小さい番号が先）。

1. 角（a1, a8, h1, h8）
2. 相手の合法手を減らす手
3. 角でも X/C でもない辺
4. その他の通常のマス
5. 対応する角が空の C（角の隣）
6. 対応する角が空の X（角の斜め隣）

同じ分類の中では、着手後の相手の合法手が少ない順、さらに a1…h8 である。根の手の走査自体は `legal_places` の座標順のままなので、評価値が並んだときの選択はミニマックス個体と同じ座標順になる。

## Transposition Table

別手順で同じ盤・同じ手番に着くことがある。その評価を残りの深さつきで覚えておく表を **Transposition Table** という。キーは **Zobrist ハッシュ**（マスと石色ごとの乱数の排他的論理和。手番が白ならもう 1 個の乱数を足す）である。同じ残り深さの結果だけ再利用する。表は 1 着手の根探索が終わったら捨て、対局をまたいで残さない。

## 葉の一次結合

葉の点数は、手番側から見た差の一次結合である。

\[
\begin{aligned}
v &= 50\,\Delta M + 1000\,\Delta C_{\text{角}} - 150\,\Delta X - 80\,\Delta C \\
  &\quad - 10\,\Delta F + W\,\Delta D
\end{aligned}
\]

- \(\Delta M\): Mobility 差（自分の合法手数 − 相手の合法手数）
- \(\Delta C_{\text{角}}\): 角の石数差
- \(\Delta X\), \(\Delta C\): 空き角に紐づく X / C の石数差（その角を既に取っていれば数えない）
- \(\Delta F\): Frontier 差（空きマスに隣する自分の石 − 相手の石）
- \(\Delta D\): 石数差
- \(W\): 空きマス数（Game Phase）。40 以上は 1、20〜39 は 5、10〜19 は 20、9 以下は 100

空きマスが少なくても終局の石数読みには切り替えない。対局中に学習済みモデルも OpenRouter も呼ばない。
