# RL 改善 段階 0（開始局面集合と基準線）

数値の正本は [`rl-stage0.json`](rl-stage0.json) と [`rl-openings.json`](rl-openings.json) である。本ファイルはそれを要約し、総当たりとの傾向を書く。表の小数は閲覧用に丸めた写しであり、再計算して正本にしない。対局の再実行は CI に載せない。

提案書は作業稿であり、本ファイルは [`docs/source-of-truth/`](../source-of-truth/) には置かない。対局数や勝率の数値目標は **shall にはしない**。

## 測ったもの

現行カタログの「強化学習 (自己対局)」1 体（`models/rl.json`。Issue #125 の記録では 5000 局）。評価関数の差し替え、αβ への搭載、新しいカタログ個体、既存 `rl` の置き換えはしていない。

| 項目 | 内容 |
| --- | --- |
| 候補 | カタログ「強化学習 (自己対局)」。線形 TD(0) greedy |
| 相手 | ランダム (一様)、ルールベース (位置評価)、ルールベース (ミニマックス) 深さ 4 |
| 開始局面 | 初形から 4〜8 手を一様乱択。200 局面。乱数種 `20260922` |
| 対局 | 各局面で先後入れ替え。3 相手 × 200 × 2 = 1200 局 |
| 勝敗 | 公式スコア。勝率は（勝 + 0.5×分）/ 局数 |
| 石数差 | 盤上の石数（RL − 相手） |
| 95% 区間 | 標本平均の正規近似。勝率の区間が 0.5 をまたぐときは「この局数では区別できない」 |

学習途中の重みは `python -m reversi.train.rl --snapshot-every N --snapshot-dir DIR` で書き、同じ開始局面・同じ相手で `rl_eval.py --snapshots-dir DIR` が測る。本記録の学習曲線は現行成果物の 1 点である。

## 総当たり（19:09）との傾向

[`round-robin.md`](round-robin.md) の 2026-09-21 19:09 では、強化学習 (自己対局) は勝ち点 9.5・5 位。一様乱択は 5 点・11 位、位置評価は 9 点・6 位、ミニマックスは 17.5 点・2 位。総当たりは組み合わせごとに初形から 2 局だけである。

- 一様乱択より上、ミニマックスより下、という順序は本評価でも同じである。
- 位置評価との差は総当たりでは 0.5 点（2 局×先後の粗さ）で、本評価では勝率 0.148 まで開く。総当たりの 5 位は、開始局面を増やした測定では位置評価に勝てていない。

以降の比較は、この JSON の開始局面集合と相手を固定したまま行う。
